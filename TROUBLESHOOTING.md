# 🔧 Решение проблем

## Проблема: Приложение не запускается локально

### Шаг 1: Проверьте установку Node.js

Откройте PowerShell и выполните:
```bash
node --version
npm --version
```

Если команды не работают, установите Node.js с [nodejs.org](https://nodejs.org/)

### Шаг 2: Установите зависимости

Убедитесь, что вы в папке проекта, затем:
```bash
cd "C:\Users\maxse\Downloads\Berns test"
npm install
```

### Шаг 3: Запустите приложение

```bash
npm run dev
```

Вы должны увидеть что-то вроде:
```
  VITE v5.0.8  ready in 500 ms

  ➜  Local:   http://localhost:3000/
```

### Шаг 4: Откройте в браузере

Перейдите по адресу `http://localhost:3000`

## Проблема: Ошибка "Cannot find module"

**Решение**: 
1. Удалите папку `node_modules` и файл `package-lock.json`
2. Выполните `npm install` заново

---

## Проблема: Приложение запускается, но не работает

### Проверьте консоль браузера

1. Откройте приложение в браузере
2. Нажмите F12 (откроется DevTools)
3. Перейдите на вкладку "Console"
4. Посмотрите на ошибки (красным цветом)

### Частые ошибки:

#### "Supabase не настроен"
**Это нормально!** Приложение работает и без Supabase. Результаты просто не будут сохраняться.

Чтобы настроить Supabase:
1. Создайте файл `.env` в корне проекта
2. Скопируйте содержимое из `.env.example`
3. Заполните значения из Supabase (Settings → API)

#### "Cannot read property..."
**Решение**: Обновите страницу (F5) или перезапустите сервер разработки

---

## Проблема: Порт 3000 уже занят

Если вы видите ошибку о том, что порт занят:

1. Измените порт в `vite.config.ts`:
```typescript
server: {
  port: 3001, // или любой другой свободный порт
  host: true
}
```

2. Перезапустите сервер

---

## Проблема: TypeScript ошибки

Если вы видите ошибки TypeScript:

1. Проверьте, что все файлы сохранены
2. Перезапустите сервер разработки
3. Убедитесь, что установлены все зависимости: `npm install`

---

## Проблема: График не отображается

**Причины:**
1. Нет сохраненных результатов (пройдите тест несколько раз)
2. Supabase не настроен (результаты не сохраняются)
3. Ошибка загрузки данных

**Решение:**
1. Настройте Supabase (см. инструкции выше)
2. Пройдите тест несколько раз
3. Проверьте консоль браузера на ошибки

---

## Проблема: Результаты не сохраняются

**Причины:**
1. Файл `.env` не создан или не заполнен
2. Неправильные значения в `.env`
3. Таблица не создана в Supabase
4. Ошибки в консоли браузера

**Решение:**
1. Проверьте наличие файла `.env`
2. Убедитесь, что значения правильные (без лишних пробелов)
3. Выполните SQL из `supabase_setup.sql` в Supabase
4. Проверьте консоль браузера (F12) на ошибки

---

## Проблема: Telegram Mini App не открывается

**Причины:**
1. URL неправильный в BotFather
2. Приложение не задеплоено на Vercel
3. Ошибки в консоли браузера

**Решение:**
1. Убедитесь, что приложение задеплоено на Vercel
2. Проверьте URL в BotFather (должен быть HTTPS)
3. Проверьте, что URL правильный (без лишних символов)

---

## Работа без Supabase

**Приложение работает и без Supabase!** 

Без настроенного Supabase:
- ✅ Можно проходить тест
- ✅ Можно видеть результаты
- ❌ Результаты не сохраняются
