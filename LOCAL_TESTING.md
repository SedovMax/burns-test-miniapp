# 🧪 Тестирование локально

## Проблема: Результаты не сохраняются

Если вы тестируете приложение локально (не в Telegram), результаты не сохраняются по следующим причинам:

1. **Нет Telegram Web App** - поэтому `userId` будет `null`
2. **Нужен файл .env** - для подключения к Supabase

## ✅ Решение

### Шаг 1: Создайте файл .env

В корне проекта создайте файл `.env` со следующим содержимым:

```
VITE_SUPABASE_URL=ваш_url_из_supabase
VITE_SUPABASE_ANON_KEY=ваш_ключ_из_supabase
```

**Важно**: 
- Файл должен называться именно `.env` (с точкой в начале)
- Без пробелов вокруг знака `=`
- Без кавычек вокруг значений

### Шаг 2: Получите данные из Supabase

1. Перейдите на [supabase.com](https://supabase.com)
2. Войдите в свой проект
3. Перейдите в **Settings** → **API**
4. Скопируйте:
   - **Project URL** → это `VITE_SUPABASE_URL`
   - **anon public** ключ → это `VITE_SUPABASE_ANON_KEY`

### Шаг 3: Перезапустите dev сервер

**Важно**: После создания/изменения файла `.env` нужно перезапустить сервер!

1. Остановите сервер (Ctrl+C в PowerShell)
2. Запустите снова:
```bash
npm run dev
```

### Шаг 4: Проверьте консоль браузера

1. Откройте приложение в браузере
2. Нажмите **F12** (откроется DevTools)
3. Перейдите на вкладку **Console**
4. Вы должны увидеть:
   - `🔧 Настройки Supabase:` - статус подключения
   - `✅ Supabase клиент успешно создан` - если всё правильно
   - `⚠️ Supabase не настроен` - если что-то не так

### Шаг 5: Проверьте тестовый User ID

Приложение автоматически создает тестовый `userId` для локального тестирования:
- Он сохраняется в `localStorage`
- Вы увидите его в консоли: `Создан новый тестовый userId: test_1234567890`

### Шаг 6: Используйте DevTools

В правом нижнем углу есть кнопка 🔧 - это инструменты разработчика:
- Показывает текущий `userId`
- Позволяет изменить `userId` вручную
- Показывает статус Supabase

## 🔍 Диагностика проблем

### Проблема: "Supabase не настроен"

**Проверьте:**
1. ✅ Файл `.env` существует в корне проекта
2. ✅ Файл `.env` содержит обе переменные
3. ✅ Нет лишних пробелов или символов
4. ✅ Сервер перезапущен после создания `.env`

**Пример правильного .env:**
```
VITE_SUPABASE_URL=https://abcdefghijklmnop.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmFzZSIsInJlZiI6ImFiY2RlZmdoaWprbG1ub3AiLCJyb2xlIjoiYW5vbiIsImlhdCI6MTYzODk2NzI4MCwiZXhwIjoxOTU0NTQzMjgwfQ.abcdefghijklmnopqrstuvwxyz1234567890
```

### Проблема: "Ошибка сохранения результата"

**Проверьте в консоли браузера:**
1. Какая именно ошибка (message, code, details)
2. Правильно ли создана таблица в Supabase
3. Правильно ли настроены RLS политики

**Частые ошибки:**
- `relation "test_results" does not exist` - таблица не создана
  - **Решение**: Выполните SQL из `supabase_setup.sql` в Supabase
- `new row violates row-level security policy` - неправильные RLS политики
  - **Решение**: Проверьте политики в Supabase (должны быть разрешены INSERT и SELECT)

### Проблема: "User ID не получен"

Это нормально для локального тестирования! Приложение автоматически создает тестовый `userId`.

Если этого не происходит:
1. Проверьте консоль браузера
2. Очистите `localStorage` (DevTools → Application → Local Storage → Clear)
3. Перезагрузите страницу

## 🧪 Тестирование сохранения

1. **Откройте консоль браузера** (F12 → Console)
2. **Пройдите тест**
3. **После завершения** проверьте консоль:
   - Должно быть: `✅ Результат успешно сохранен в Supabase`
   - Или ошибка с деталями

4. **Проверьте в Supabase**:
   - Перейдите в Supabase → Table Editor → test_results
   - Должна появиться новая запись

## 📊 Проверка графика

После сохранения результатов:
1. Нажмите "Посмотреть динамику" на экране результатов
2. Должен появиться график с вашими результатами
3. Если график пустой - пройдите тест еще раз

## 🎯 Быстрая проверка

Выполните эти шаги по порядку:

1. ✅ Файл `.env` создан и заполнен
2. ✅ Сервер перезапущен
3. ✅ В консоли видно `✅ Supabase клиент успешно создан`
4. ✅ В консоли видно тестовый `userId`
5. ✅ Пройден тест
6. ✅ В консоли видно `✅ Результат успешно сохранен`
7. ✅ В Supabase появилась запись

Если все шаги выполнены - всё работает! 🎉
