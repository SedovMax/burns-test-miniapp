# 🌐 Простой способ: Создание репозитория через веб-интерфейс GitHub

Это самый простой способ для начинающих! Мы создадим репозиторий на GitHub.com, а потом загрузим файлы.

## 🚀 Пошаговая инструкция

### Шаг 1: Создайте репозиторий на GitHub.com

1. Откройте [github.com](https://github.com) в браузере
2. Войдите в свой аккаунт GitHub
3. Нажмите зеленую кнопку **"+"** в правом верхнем углу
4. Выберите **"New repository"**

5. Заполните форму:
   ```
   Repository name: burns-test-miniapp
   Description: Telegram Mini App для теста депрессии Бернса
   Public: ☑ (или Private, если хотите приватный)
   ⬜ Add a README file (НЕ отмечайте!)
   ⬜ Add .gitignore (НЕ отмечайте!)
   ⬜ Choose a license (НЕ выбирайте!)
   ```

6. Нажмите зеленую кнопку **"Create repository"**

### Шаг 2: GitHub покажет инструкции

После создания репозитория GitHub покажет страницу с инструкциями. **НЕ закрывайте эту страницу!**

Вы увидите что-то вроде:
```
…or create a new repository on the command line
…or push an existing repository from the command line
```

### Шаг 3: Загрузите файлы через GitHub Desktop (простой способ)

Теперь, когда репозиторий создан на GitHub, мы подключим к нему вашу папку:

1. **Откройте GitHub Desktop**
2. Нажмите **"File"** → **"Clone repository"**
3. Перейдите на вкладку **"GitHub.com"**
4. Найдите репозиторий **"burns-test-miniapp"** в списке
5. Нажмите **"Clone"**
6. Выберите папку для клонирования (например: `C:\Users\maxse\Downloads\`)
7. Нажмите **"Clone"**

**Важно:** Это создаст новую папку `burns-test-miniapp` с пустым репозиторием.

### Шаг 4: Скопируйте файлы проекта

1. Откройте Проводник Windows
2. Откройте папку: `C:\Users\maxse\Downloads\Berns test`
3. Выделите **ВСЕ файлы и папки** (Ctrl+A)
4. Скопируйте (Ctrl+C)
5. Откройте папку: `C:\Users\maxse\Downloads\burns-test-miniapp` (та, что создал GitHub Desktop)
6. Вставьте файлы (Ctrl+V)

**Исключения:** НЕ копируйте:
- Папку `.git` (если есть)
- Папку `node_modules` (можно не копировать, она большая)

### Шаг 5: Создайте коммит в GitHub Desktop

1. Вернитесь в **GitHub Desktop**
2. Теперь слева должен появиться список **ВСЕХ** файлов проекта!
3. Внизу слева в поле **"Summary"** введите:
   ```
   Initial commit: All project files
   ```
4. Нажмите кнопку **"Commit to main"** (внизу слева)
5. Дождитесь завершения

### Шаг 6: Загрузите на GitHub

1. После создания коммита нажмите кнопку **"Push origin"** (вверху)
2. Дождитесь завершения загрузки
3. Обновите страницу на GitHub.com - должны появиться все файлы!

## ✅ Готово!

Теперь все файлы на GitHub! Вы можете:
- Просматривать код на GitHub.com
- Подключить репозиторий к Vercel
- Поделиться репозиторием
