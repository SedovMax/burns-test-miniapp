# 🖥️ Пошаговая инструкция для GitHub Desktop

Это самая простая инструкция для загрузки проекта в GitHub с помощью GitHub Desktop.

## 📋 Что вам понадобится

- ✅ GitHub Desktop (установлен и вы вошли в аккаунт)
- ✅ Аккаунт GitHub
- ✅ Проект в папке `C:\Users\maxse\Downloads\Berns test`

## 🚀 Шаги

### Шаг 1: Создайте репозиторий на GitHub.com

1. Откройте [github.com](https://github.com) в браузере
2. Войдите в свой аккаунт
3. Нажмите зеленую кнопку **"+"** в правом верхнем углу
4. Выберите **"New repository"**

5. Заполните форму:
   ```
   Repository name: burns-test-miniapp
   Description: Telegram Mini App для теста депрессии Бернса
   Public: ☑ (или Private, если хотите)
   ⬜ Add a README file (НЕ отмечайте!)
   ⬜ Add .gitignore (НЕ отмечайте!)
   ⬜ Choose a license (НЕ выбирайте!)
   ```

6. Нажмите **"Create repository"**

### Шаг 2: Откройте GitHub Desktop

1. Запустите **GitHub Desktop**
2. Убедитесь, что вы вошли в свой аккаунт GitHub

### Шаг 3: Добавьте проект в GitHub Desktop

#### Вариант A: Если репозиторий еще не создан в папке

1. В GitHub Desktop нажмите **"File"** → **"New repository"**
2. Заполните:
   ```
   Name: burns-test-miniapp
   Description: Telegram Mini App для теста депрессии Бернса
   Local path: C:\Users\maxse\Downloads\Berns test
   Git ignore: Node
   ```
3. Нажмите **"Create repository"**

#### Вариант B: Если репозиторий уже создан в папке

1. В GitHub Desktop нажмите **"File"** → **"Add local repository"**
2. Нажмите **"Choose..."**
3. Выберите папку: `C:\Users\maxse\Downloads\Berns test`
4. Нажмите **"Add repository"**

### Шаг 4: Проверьте файлы

1. В GitHub Desktop слева вы увидите список файлов
2. Все файлы проекта должны быть в списке
3. Файл `.env` и папка `node_modules` НЕ должны быть в списке (это нормально!)

### Шаг 5: Создайте первый коммит

1. Внизу слева в поле **"Summary"** введите:
   ```
   Initial commit: Burns depression test mini app
   ```

2. Нажмите кнопку **"Commit to main"** (внизу слева)

3. Дождитесь завершения - вы увидите сообщение "Commit created locally"

### Шаг 6: Опубликуйте на GitHub

1. После создания коммита вверху появится кнопка **"Publish repository"**
2. Нажмите **"Publish repository"**
3. Убедитесь, что:
   - **Name**: `burns-test-miniapp`
   - **Keep this code private**: отмечено, если хотите приватный репозиторий
4. Нажмите **"Publish repository"**
5. Дождитесь завершения - вы увидите "Published to GitHub"

### Шаг 7: Проверьте на GitHub.com

1. Откройте [github.com](https://github.com) в браузере
2. Найдите репозиторий `burns-test-miniapp` в списке
3. Откройте его
4. Убедитесь, что все файлы загружены

## 🔄 Что делать при изменениях

Когда вы измените файлы в проекте:

1. Откройте GitHub Desktop
2. Вы увидите список измененных файлов слева
3. Внизу введите сообщение коммита (например: "Исправлена ошибка сохранения")
4. Нажмите **"Commit to main"**
5. Нажмите **"Push origin"** (вверху) для загрузки на GitHub

## ❓ Решение проблем

### Проблема: "nothing to commit, working tree clean"

**Это нормально!** Это означает, что все файлы уже закоммичены.

**Что делать**:
1. Проверьте, что файлы видны в GitHub Desktop
2. Если файлы есть, но они не в списке изменений - они уже закоммичены
3. Просто нажмите **"Publish repository"** (если еще не опубликовали)

### Проблема: GitHub Desktop не видит файлы

**Решение**:
1. Убедитесь, что вы открыли правильную папку
2. Нажмите **"Repository"** → **"Show in Explorer"**
3. Должна открыться папка `C:\Users\maxse\Downloads\Berns test`
4. Если папка неправильная, закройте репозиторий и добавьте правильную

### Проблема: Файл .env в списке

**Решение**:
1. Файл `.env` должен быть в `.gitignore` (он уже там)
2. Если он все равно в списке:
   - В GitHub Desktop нажмите на файл `.env`
   - Нажмите правой кнопкой мыши → **"Ignore"**
   - Выберите **"Ignore this file"**

### Проблема: Не могу опубликовать репозиторий

**Решение**:
1. Убедитесь, что вы вошли в GitHub Desktop
2. Проверьте интернет-соединение
3. Попробуйте еще раз
