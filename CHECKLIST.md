# ✅ Чек-лист проверки работы приложения

Используйте этот чек-лист, чтобы проверить, что всё работает правильно.

## 📋 Перед началом

- [ ] Node.js установлен (`node --version` показывает версию)
- [ ] Зависимости установлены (`npm install` выполнен)
- [ ] Проект Supabase создан
- [ ] Таблица `test_results` создана в Supabase (SQL из `supabase_setup.sql` выполнен)

## 🔧 Настройка .env

- [ ] Файл `.env` создан в корне проекта
- [ ] В файле `.env` есть `VITE_SUPABASE_URL=ваш_url`
- [ ] В файле `.env` есть `VITE_SUPABASE_ANON_KEY=ваш_ключ`
- [ ] Нет лишних пробелов или символов
- [ ] Значения скопированы из Supabase (Settings → API)

## 🚀 Запуск приложения

- [ ] Сервер запущен (`npm run dev`)
- [ ] Приложение открыто в браузере (`http://localhost:3000`)
- [ ] Нет ошибок в консоли браузера (F12 → Console)

## 🔍 Проверка консоли

Откройте консоль браузера (F12 → Console) и проверьте:

- [ ] Видно `🔧 Настройки Supabase:` с `isConfigured: true`
- [ ] Видно `✅ Supabase клиент успешно создан`
- [ ] Видно тестовый `userId` (например: `test_1234567890`)
- [ ] Нет ошибок (красным цветом)

## 🧪 Тестирование сохранения

- [ ] Прошел тест (ответил на все 25 вопросов)
- [ ] После завершения в консоли видно: `✅ Результат успешно сохранен в Supabase`
- [ ] Нет ошибок сохранения в консоли
- [ ] В Supabase (Table Editor → test_results) появилась новая запись

## 📊 Проверка графика

- [ ] Нажал "Посмотреть динамику" на экране результатов
- [ ] График отображается
- [ ] На графике виден результат теста
- [ ] Статистика показывает правильные данные (количество тестов, средний балл)

## 🎯 Итоговая проверка

- [ ] Тест проходит без ошибок
- [ ] Результаты сохраняются в Supabase
- [ ] График отображается корректно
- [ ] Можно пройти несколько тестов подряд
- [ ] Все результаты видны в графике

---

## ❌ Если что-то не работает

### Результаты не сохраняются

1. Проверьте консоль браузера на ошибки
2. Проверьте, что файл `.env` правильный
3. Убедитесь, что сервер перезапущен после создания `.env`
4. Проверьте, что таблица создана в Supabase
5. Проверьте RLS политики в Supabase

### График не показывается

1. Убедитесь, что есть сохраненные результаты
2. Пройдите тест еще раз
3. Проверьте консоль браузера на ошибки загрузки данных

### Ошибки в консоли

1. Скопируйте текст ошибки
2. Проверьте раздел "Решение проблем" в `TROUBLESHOOTING.md`
3. Проверьте `LOCAL_TESTING.md` для подробных инструкций

---

**Если все пункты отмечены ✅ - приложение работает правильно! 🎉**
