# 🔍 Руководство по отладке

## Проверка userId в консоли

После загрузки страницы откройте консоль браузера (F12 → Console) и проверьте следующие сообщения:

### ✅ Правильная последовательность сообщений:

```
🔍 Инициализация приложения...
Проверка Telegram Web App: {hasTelegram: true/false, hasWebApp: true/false, ...}
🌐 Локальный режим (не в Telegram)
✨ Создан новый тестовый userId: test_1234567890
👤 userId установлен: test_1234567890
🔧 Настройки Supabase: {hasUrl: true, hasKey: true, ...}
✅ Supabase клиент успешно создан
```

### Если видите сохраненный userId:

```
🌐 Локальный режим (не в Telegram)
📋 Используется сохраненный тестовый userId: test_1234567890
👤 userId установлен: test_1234567890
```

## Проблема: userId не создается

### Шаг 1: Проверьте консоль

Откройте консоль (F12) и найдите сообщение `🔍 Инициализация приложения...`

Если его нет - страница не загрузилась полностью. Обновите страницу (F5).

### Шаг 2: Проверьте localStorage

В консоли браузера выполните:

```javascript
localStorage.getItem('test_user_id')
```

Если вернется `null` - userId не был сохранен.
Если вернется строка (например, `test_1234567890`) - userId сохранен.

### Шаг 3: Очистите localStorage (если нужно)

Если нужно создать новый userId:

```javascript
localStorage.removeItem('test_user_id')
location.reload()
```

### Шаг 4: Проверьте, что код выполняется

В консоли должны быть сообщения:
- `🔍 Инициализация приложения...`
- `🌐 Локальный режим (не в Telegram)` или `✅ Обнаружен Telegram`
- `✨ Создан новый тестовый userId:` или `📋 Используется сохраненный тестовый userId:`

Если этих сообщений нет - возможно, есть ошибка JavaScript. Проверьте вкладку Console на красные ошибки.

## Проверка сохранения результатов

### Шаг 1: Пройдите тест

После завершения теста проверьте консоль на сообщения:

```
Попытка сохранить результат: {userId: "test_1234567890", isSupabaseConfigured: true, ...}
Отправка данных в Supabase: {...}
✅ Результат успешно сохранен в Supabase: [...]
```

### Шаг 2: Если видите ошибку

```
❌ Ошибка сохранения результата в Supabase: {...}
```

Скопируйте полный текст ошибки и проверьте:
1. Правильность настроек Supabase
2. Создана ли таблица
3. Настроены ли RLS политики

## Использование DevTools

В правом нижнем углу есть кнопка 🔧 - это инструменты разработчика.

Она показывает:
- Текущий userId
- Статус Supabase
- Позволяет изменить userId вручную

**Важно**: Кнопка показывается только в локальном режиме (не в Telegram).

## Частые проблемы

### Проблема: "userId не установлен (null)"

**Причины:**
1. Код инициализации не выполнился
2. Есть ошибка JavaScript
3. localStorage заблокирован

**Решение:**
1. Проверьте консоль на ошибки
2. Обновите страницу (F5)
3. Проверьте, что JavaScript включен

### Проблема: "Используется сохраненный userId" (но хотите новый)

**Решение:**
1. Откройте консоль (F12)
2. Выполните: `localStorage.removeItem('test_user_id')`
3. Обновите страницу (F5)

### Проблема: Сообщения не появляются в консоли

**Причины:**
1. Консоль отфильтрована
2. Сообщения в другом месте
3. Код не загрузился

**Решение:**
1. Убедитесь, что в консоли выбрано "All levels" (все уровни)
2. Очистите консоль (кнопка очистки или Ctrl+L)
3. Обновите страницу (F5)

## Команды для проверки в консоли

### Проверить userId:
```javascript
localStorage.getItem('test_user_id')
```

### Проверить настройки Supabase:
```javascript
console.log('URL:', import.meta.env.VITE_SUPABASE_URL)
console.log('Key:', import.meta.env.VITE_SUPABASE_ANON_KEY ? 'Установлен' : 'Не установлен')
```

### Очистить все данные:
```javascript
localStorage.clear()
location.reload()
```

### Принудительно создать новый userId:
```javascript
localStorage.removeItem('test_user_id')
const newUserId = 'test_' + Date.now()
localStorage.setItem('test_user_id', newUserId)
console.log('Создан новый userId:', newUserId)
location.reload()
```

## Что делать, если ничего не помогает

1. **Очистите кэш браузера** (Ctrl+Shift+Delete)
2. **Перезапустите dev сервер** (остановите и запустите заново)
3. **Проверьте, что файлы сохранены** (все изменения должны быть на диске)
4. **Проверьте консоль на ошибки** (красным цветом)

---

**Если проблема не решена**, скопируйте все сообщения из консоли и отправьте для анализа.
