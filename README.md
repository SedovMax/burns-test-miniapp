# Тест депрессии Бернса - Telegram Mini App

Это мини-приложение для Telegram, которое позволяет пользователям проходить тест депрессии Бернса, сохранять результаты и отслеживать динамику своего эмоционального состояния в графическом виде.

## 📱 Описание проекта

Приложение состоит из:
- **Экрана теста**: Последовательное прохождение 25 вопросов теста Бернса
- **Экрана результатов**: Отображение результата с интерпретацией
- **Экрана истории**: График динамики депрессии и история всех прохождений

### Особенности:
- ✅ Последовательное прохождение вопросов
- ✅ Возможность вернуться к предыдущему вопросу
- ✅ Автоматическое сохранение результатов
- ✅ График динамики депрессии
- ✅ Адаптивный дизайн для мобильных устройств
- ✅ Интеграция с Telegram Web App API

## 🛠 Технологии

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **Vite** - Сборщик и dev-сервер
- **Supabase** - База данных для хранения результатов

### Шаг 2: Настройка переменных окружения

1. Создайте файл `.env` в корне проекта (скопируйте `.env.example`):

Для разработки запустите:
```bash

```

Приложение откроется по адресу `http://localhost:3000`

## 🗄 Настройка Supabase

### Шаг 1: Создание проекта в Supabase

1. Перейдите на [supabase.com](https://supabase.com) и войдите в свой аккаунт
2. Нажмите "New Project"
3. Заполните форму:
   - **Name**: `burns-test` (или любое другое имя)
   - **Database Password**: придумайте надежный пароль (сохраните его!)
   - **Region**: выберите ближайший регион
4. Нажмите "Create new project" и подождите несколько минут

### Шаг 2: Получение ключей API

1. В проекте Supabase перейдите в **Settings** → **API**
2. Найдите раздел **Project API keys**
3. Скопируйте:
   - **Project URL** - это ваш `VITE_SUPABASE_URL`
   - **anon public** ключ - это ваш `VITE_SUPABASE_ANON_KEY`

4. Вставьте эти значения в файл `.env`:
```
VITE_SUPABASE_URL=https://ваш-проект.supabase.co
VITE_SUPABASE_ANON_KEY=ваш_anon_ключ
```

### Шаг 3: Создание таблицы в базе данных

1. В Supabase перейдите в **SQL Editor** (в левом меню)
2. Нажмите "New query"
3. Откройте файл `supabase_setup.sql` из этого проекта
4. Скопируйте весь SQL код из файла
5. Вставьте его в SQL Editor в Supabase
6. Нажмите "Run" (или Ctrl+Enter)

Таблица `test_results` будет создана автоматически!

### Проверка таблицы

1. Перейдите в **Table Editor** в Supabase
2. Вы должны увидеть таблицу `test_results`
3. Таблица должна быть пустой (данные появятся после первого прохождения теста)

## 🤖 Настройка Telegram бота

### Шаг 1: Создание бота через BotFather

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "Тест депрессии Бернса")
   - Введите username бота (должен заканчиваться на `bot`, например: `burns_test_bot`)
4. **Сохраните токен**, который даст вам BotFather (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Настройка Mini App

1. Отправьте BotFather команду `/newapp`
2. Выберите вашего бота из списка
3. Введите название приложения (например: "Тест Бернса")
4. Введите описание (например: "Пройдите тест депрессии Бернса и отслеживайте динамику")
5. Загрузите иконку (квадратное изображение, минимум 640x640px)
6. Когда спросит про Web App URL, введите: `https://ваш-домен.vercel.app` (пока можете ввести временный URL, потом обновите)

**Важно**: После деплоя на Vercel вернитесь и обновите URL командой `/myapps` → выберите приложение → "Edit" → "Web App URL"

### Шаг 3: Добавление кнопки в бота

Создайте файл `bot_example.py` (пример ниже) или используйте любой другой способ для настройки бота.

**Пример кода для бота (Python):**

```python
import os
from telegram import Bot, InlineKeyboardButton, InlineKeyboardMarkup

# Замените на ваш токен от BotFather
BOT_TOKEN = "ваш_токен_от_botfather"
WEB_APP_URL = "https://ваш-домен.vercel.app"

bot = Bot(token=BOT_TOKEN)

async def start(update, context):
    keyboard = [
        [InlineKeyboardButton(
            "🧠 Пройти тест Бернса",
            web_app={"url": WEB_APP_URL}
        )]
    ]
    reply_markup = InlineKeyboardMarkup(keyboard)
    await update.message.reply_text(
        "Добро пожаловать! Нажмите кнопку ниже, чтобы пройти тест депрессии Бернса.",
        reply_markup=reply_markup
    )

# Запуск бота (нужно установить python-telegram-bot)
# pip install python-telegram-bot
```

## 🚀 Развертывание на Vercel

### Шаг 1: Подготовка к деплою

1. Убедитесь, что все изменения закоммичены в Git:
```bash
git add .
git commit -m "Initial commit"
```

2. Запушьте в GitHub:
```bash
git push origin main
```

### Шаг 2: Подключение к Vercel

1. Перейдите на [vercel.com](https://vercel.com) и войдите через GitHub
2. Нажмите "Add New..." → "Project"
3. Выберите ваш репозиторий из списка
4. Нажмите "Import"

### Шаг 3: Настройка переменных окружения в Vercel

1. В разделе "Environment Variables" добавьте:
   - **Key**: `VITE_SUPABASE_URL`
   - **Value**: ваш URL из Supabase
   - Отметьте все окружения (Production, Preview, Development)

2. Добавьте вторую переменную:
   - **Key**: `VITE_SUPABASE_ANON_KEY`
   - **Value**: ваш anon key из Supabase
   - Отметьте все окружения

3. Нажмите "Deploy"

### Шаг 4: Получение URL приложения

1. После успешного деплоя Vercel даст вам URL (например: `https://burns-test.vercel.app`)
2. **Скопируйте этот URL** - он понадобится для настройки бота

### Шаг 5: Обновление URL в BotFather

1. Вернитесь к BotFather в Telegram
2. Отправьте `/myapps`
3. Выберите ваше приложение
4. Выберите "Edit" → "Web App URL"
5. Вставьте URL из Vercel
6. Готово! 🎉

## 🐛 Решение проблем

### Проблема: "Cannot connect to Supabase"
- Проверьте, что переменные окружения в `.env` заполнены правильно
- Убедитесь, что таблица создана в Supabase
- Проверьте, что RLS политики настроены правильно

### Проблема: "Mini App не открывается"
- Проверьте URL в BotFather - он должен быть HTTPS
- Убедитесь, что домен задеплоен на Vercel
- Проверьте, что бот правильно настроен

### Проблема: "График не отображается"
- Убедитесь, что есть сохраненные результаты
- Проверьте консоль браузера на ошибки
- Убедитесь, что Recharts установлен: `npm install`
